\# ETAP Stock Management



Web application for centralized stock management and inventory tracking, developed for ETAP (Entreprise Tunisienne d'Activités Pétrolières).



\## Features



\- User authentication and role-based access (Admin / Operator)

\- CRUD management for products, categories and locations

\- Stock in/out tracking (deliveries and withdrawals)

\- Automatic stock quantity updates

\- Business rule validation (e.g. no withdrawal beyond available stock)

\- Centralized dashboard with real-time stock overview

\- Action logging and traceability

\- User profile management
